# Candidate Intelligence Brief — AI Resume vs. Job Description Analyzer

A self-contained **Streamlit** app that acts as an **AI Talent Intelligence and
Recruitment Assistant**. Paste (or upload) a candidate's resume and a target
job description, and it returns a full structured analysis — ATS score,
job fit %, skill gap analysis, project relevance, resume rewrite suggestions,
interview prep, a learning roadmap, career recommendations, and a final
hiring recommendation — rendered as an interactive "candidate intelligence
brief" with gauges, radar charts, and downloadable Markdown/JSON reports.

The analysis is generated by an LLM using a carefully structured prompt that
enforces a strict JSON schema. You can point it at **Claude (Anthropic)** or
at **any OpenRouter-hosted model** (DeepSeek, Grok, Llama, etc.) — just by
flipping one environment variable, no code changes required.

- Python 3.9+

## 3. Setup

### Step 1 — Create a virtual environment (recommended)

```bash
cd resume_analyzer
python3 -m venv venv
source venv/bin/activate        # On Windows: venv\Scripts\activate
```

### Step 2 — Install dependencies

```bash
pip install -r requirements.txt
```

### Step 3 — Configure your `.env` file

A `.env` file is already included with placeholder values. Open it and set
your real key(s):

```env
# Pick the backend:
LLM_PROVIDER=openrouter          # or "anthropic"

# OpenRouter (used when LLM_PROVIDER is not "anthropic")
OPENROUTER_API_KEY=sk-or-v1-your-real-key-here
OPENROUTER_MODEL=deepseek/deepseek-chat-v3-0324
OPENROUTER_MAX_TOKENS=8000
OPENROUTER_TEMPERATURE=0.3

# Anthropic (used when LLM_PROVIDER=anthropic)
ANTHROPIC_API_KEY=sk-ant-api03-your-real-key-here
CLAUDE_MODEL=claude-sonnet-4-6
CLAUDE_MAX_TOKENS=8000
```

> ⚠️ **Never commit your real `.env` file with live keys to a public
> repository.** Use `.env.example` as the template for collaborators and
> keep `.env` in `.gitignore` (already configured).

You can also override the provider, model, and API key directly from the
app's sidebar at runtime, without editing `.env` or restarting.

### Step 4 — Run the app

```bash
streamlit run streamlit_app.py
```

Then open your browser at: **http://localhost:8501**

## 4. How to Use

1. Open the sidebar and confirm the **LLM Provider** and **model** are set
   the way you want (defaults come from `.env`).
2. Paste the **Job Description** into the left panel.
3. Provide the candidate's resume either by:
   - Pasting raw text / RAG-retrieved resume context into the **Paste Text**
     tab, or
   - Uploading a `.pdf`, `.docx`, or `.txt` file in the **Upload File** tab.
4. Click **Run Full Analysis**.
5. The report renders across tabs:
   1. Overview (ATS score + Job Fit gauges)
   2. Skills (matching / partial / missing / emerging)
   3. Project Relevance Analysis
   4. Resume Quality Review (radar chart)
   5. Recruiter Feedback
   6. Resume Rewrite Suggestions
   7. Interview Preparation
   8. Learning Roadmap
   9. Career Recommendations
   10. Final Hiring Recommendation
6. Download the full report as **Markdown** or **raw JSON** from the buttons
   above the report.

## 5. Switching Models

Because everything not explicitly set to `anthropic` is routed through
OpenRouter, switching models is just an env var (or sidebar field) change:

| Want to use…              | `LLM_PROVIDER` | `OPENROUTER_MODEL` |
|----------------------------|----------------|----------------------|
| DeepSeek V3                | `openrouter`   | `deepseek/deepseek-chat-v3-0324` |
| Grok                       | `openrouter`   | `x-ai/grok-2-latest` |
| Llama 3.3 70B               | `openrouter`   | `meta-llama/llama-3.3-70b-instruct` |
| Claude directly             | `anthropic`    | _(uses `CLAUDE_MODEL` instead)_ |

---

## 6. Notes on Accuracy

The prompt explicitly instructs the model to use **only** the supplied job
description and resume context, and to avoid inventing skills, projects, or
metrics. If a resume lacks information for a given field, the model is
instructed to say so rather than fabricate it. Always have a human reviewer
sanity-check high-stakes hiring decisions — this tool is an assistant, not a
final arbiter.
